# Weather App

🔗 Live Demo:
https://rohitpadal.github.io/Weather-App/

---

## 📌 Overview
A responsive weather application that fetches real-time weather data using a public API. Users can search for any city and view temperature, weather conditions, and related details instantly.

This project focuses on asynchronous JavaScript, API handling, and dynamic UI updates.

---

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript
- Fetch API

---

## 🚀 Features
- Search weather by city name
- Real-time API data fetching
- Async/Await implementation
- Error handling for invalid inputs
- Dynamic DOM updates
- Responsive design

---

## 👨‍💻 What I Learned
- Working with APIs using fetch()
- Handling asynchronous operations with async/await
- Managing loading and error states
- Updating UI dynamically using JavaScript

---

## ▶️ How It Works
The application fetches weather data from an external API and updates the interface based on user input.
